달레UI의 색상은 두 겹으로 나뉩니다. 색조와 단계를 그대로 담은 프리미티브 팔레트가 아래에 있고, 그 위에 쓰임새를 이름으로 드러낸 시맨틱 토큰이 있습니다. 화면을 만들 때는 시맨틱 토큰만 사용하면 라이트·다크 테마가 자동으로 대응됩니다.

## 토큰 구조

시맨틱 토큰의 이름은 '역할 · 색조 · 상태' 순서로 읽습니다.

| 구성 | 값                                                          | 설명                                                    |
| ---- | ----------------------------------------------------------- | ------------------------------------------------------- |
| 역할 | `appBg` `bg` `bgSolid` `fg` `fgSolid` `border`              | 색을 어디에 칠하는지 나타냅니다.                        |
| 색조 | `brand` `neutral` `danger` `success` `warning` `info`       | 의미를 나타냅니다. 중립 UI에는 neutral, 강조에는 brand. |
| 상태 | `hover` `active` `focus` `visited` `disabled` `placeholder` | 상호작용 상태입니다. 생략하면 기본값입니다.             |

예를 들어 `bg.brand.hover`는 브랜드 색 표면의 마우스 오버 배경입니다. 프리미티브 팔레트(`colors.violet.9`)를 화면에서 직접 참조하면 테마 전환이 깨지므로 사용하지 않습니다.

## 시맨틱 토큰

역할별 전체 목록입니다. 각 토큰이 라이트·다크 테마에서 어떤 팔레트 값으로 풀리는지 함께 보여줍니다.

### appBg · 앱 배경

페이지 전체의 바탕색입니다. 테마를 전환하면 가장 먼저 바뀌는 값으로, 화면 최상위에 한 번만 적용합니다.

<SemanticColorTable group="appBg" />

### bg · 표면 배경

카드·입력창처럼 콘텐츠를 담는 표면의 배경색입니다. 같은 이름의 fg 토큰과 짝지어 쓰면 명암비가 보장됩니다.

<SemanticColorTable group="bg" />

### bgSolid · 강조 배경

주요 버튼처럼 색을 꽉 채워 강조하는 배경색입니다. 이 위의 텍스트·아이콘에는 fgSolid를 사용합니다.

<SemanticColorTable group="bgSolid" />

### fg · 전경

표면 배경(bg) 위에 놓이는 텍스트와 아이콘 색입니다. placeholder·disabled처럼 상태별 단계를 함께 제공합니다.

<SemanticColorTable group="fg" />

### fgSolid · 강조 배경 위 전경

bgSolid 위에 올라가는 텍스트와 아이콘 색입니다. 배경과 톤을 맞춰 사용해야 명암비가 유지됩니다.

<SemanticColorTable group="fgSolid" />

### border · 경계선

테두리와 구분선 색입니다. 포커스 링에는 focus 단계를 사용해 상호작용 상태를 구분합니다.

<SemanticColorTable group="border" />

## 팔레트

시맨틱 토큰이 참조하는 원본 색상입니다. 단계는 배경에서 전경으로 가는 순서입니다. 라이트 팔레트는 1이 가장 밝고 12로 갈수록 어두워지며, `dark`로 시작하는 다크 팔레트는 반대로 1이 가장 어둡고 12로 갈수록 밝아집니다. 어느 쪽이든 9는 각 색조의 기준색으로, 버튼처럼 색을 채우는 자리에 쓰입니다.
