타이포그래피 토큰은 두 단계로 나뉩니다. 폰트·사이즈·굵기·행간·자간은 낱개 토큰이고, 이들을 조합해 이름을 붙인 것이 텍스트 스타일(textStyle)입니다. 화면에서는 낱개 토큰을 하나씩 고르는 대신 텍스트 스타일을 쓰면 조합이 어긋나지 않습니다.

## 행간과 자간

행간은 두 단계입니다. 여러 줄로 흐르는 본문에는 balanced, 한 줄로 끝나는 제목·라벨에는 tight를 사용합니다.

<LineHeightTable />

<LetterSpacingTable />

자간은 `tight`와 `balanced` 두 값이 있지만 둘 다 단위가 없어 CSS `letter-spacing`에서는 무시됩니다. 자간을 실제로 좁히려면 토큰 값에 `em` 같은 단위가 필요합니다.

## 텍스트 스타일

낱개 토큰을 조합해 이름을 붙인 스타일입니다. Panda의 textStyle 속성으로 한 번에 적용합니다. 미리보기는 기준(base) 크기로 렌더링합니다.
