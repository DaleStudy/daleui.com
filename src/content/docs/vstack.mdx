VStack은 자식을 세로 한 열로 배치합니다. [Flex](/docs/flex)에서 자주 쓰는 `direction="column"` 패턴을 `justify="top"`·`align="center"` 기본값과 함께 묶어 둔 컴포넌트입니다. 폼이나 카드처럼 자식이 가로 폭을 모두 채워야 하는 묶음에는 `align="stretch"`를 주고, 교차축 정렬이 더 복잡하면 Flex를 씁니다.

## 기본 사용법

```tsx
import { Heading, Text, VStack } from "daleui";

export function Example() {
  return (
    <VStack align="stretch" gap="8">
      <Heading level={2}>주간 리포트</Heading>
      <Text as="p" muted>
        지난 7일간의 변화를 모았습니다.
      </Text>
    </VStack>
  );
}
```
