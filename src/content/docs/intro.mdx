달레UI는 한국어 환경을 기준으로 만든 오픈소스 디자인 시스템입니다. React 컴포넌트와 디자인 토큰을 함께 제공해, 디자이너와 개발자가 같은 기준으로 접근성 높은 화면을 만들도록 돕습니다.

## 왜 달레UI인가

널리 쓰이는 디자인 시스템은 대부분 라틴 문자를 기준으로 폰트·행간·자간을 정합니다. 같은 값을 한글에 그대로 적용하면 글줄이 답답해지거나 단어 중간에서 줄이 끊깁니다. 달레UI는 본문에 Pretendard, 코드에 JetBrains Mono를 두고 행간·자간을 한글 기준으로 잡았으며, 줄바꿈 위치가 중요한 제목에는 어절 단위로 끊는 옵션을 제공합니다.

접근성은 나중에 덧붙이는 항목이 아니라 기본값입니다. 시맨틱 색상 토큰은 라이트·다크 테마의 짝으로 정의되어 배경과 전경을 같은 이름으로 맞추면 명암비가 지켜집니다. 폼·선택 컴포넌트는 [Ark UI](https://ark-ui.com)의 헤드리스 코어 위에 만들어 키보드 조작과 스크린 리더 대응이 처음부터 들어 있습니다.

스타일은 [Panda CSS](https://panda-css.com) 토큰으로 관리합니다. 완성도 높은 기본 스타일을 그대로 쓰다가도, 필요하면 스타일을 걷어내고 자유롭게 확장할 수 있습니다.

## 설계 원칙

| 원칙                  | 뜻                                                                                              |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| 한국어 사용자 중심    | 글로벌 사례를 따르되, 한국어 환경에서 가독성과 사용성이 떨어지지 않는 값을 기본값으로 삼습니다. |
| 신뢰할 수 있는 시스템 | 접근성 준수, 디자인과 구현의 일치, 예측 가능한 API를 우선합니다.                                |
| 커뮤니티 중심 발전    | 설계 결정의 근거를 공개하고, 누구나 같은 방향으로 기여할 수 있게 문서로 남깁니다.               |

이 원칙은 문서 전반에서 두 가지 실무 규칙으로 나타납니다. 첫째, 색은 프리미티브 팔레트가 아니라 [시맨틱 토큰](/docs/colors)으로 지정합니다. 그래야 테마 전환이 깨지지 않습니다. 둘째, 폰트 크기·굵기·행간을 하나씩 고르는 대신 [텍스트 스타일](/docs/typography)을 씁니다. 그래야 조합이 어긋나지 않습니다.

## 무엇이 들어 있나

- **파운데이션** — 색상·타이포그래피·스페이싱·보더·모서리 반경·아이콘 토큰입니다. 화면을 만들 때 고르는 값의 목록입니다.
- **컴포넌트** — 레이아웃, 타이포그래피, 폼, 일반 UI 컴포넌트입니다. 각 문서에서 변형·상태·Props를 확인할 수 있습니다.
- **가이드** — [접근성](/docs/a11y-guide), [폼 패턴](/docs/form-patterns)처럼 여러 컴포넌트에 공통으로 걸쳐 있는 규칙입니다.
